# Portfolio favicon sources

These checked-in files are used as local node assets so the portfolio does not depend on third-party image requests at runtime.

- `rebny.ico` — https://www.rebny.com/favicon.ico
- `nodejs.ico` — https://nodejs.org/favicon.ico
- `nodejs.svg` — https://cdn.simpleicons.org/nodedotjs (Node.js logo artwork)
- `aws.svg` — https://commons.wikimedia.org/wiki/File:Amazon_Web_Services_Logo.svg (Amazon Web Services logo, sourced from Amazon)
- `postgresql.ico` — https://www.postgresql.org/favicon.ico
- `pulumi.ico` — https://www.pulumi.com/images/favicon.ico
- `zustand.ico` — https://zustand.docs.pmnd.rs/favicon.ico
- `socket-io.png` — https://socket.io/ (official website asset from https://github.com/socketio/socket.io-website/blob/main/static/images/favicon.png)
